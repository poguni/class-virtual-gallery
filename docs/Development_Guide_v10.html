  1. 저장소를 내려받아 그 폴더에서 작업합니다: git clone https://github.com/poguni/class-virtual-gallery.git
  2. 이 문서(docs/Development_Guide_v10.md 또는 .html)를 먼저 읽게 합니다.
  3. 요청 예시:
"docs/Development_Guide_v10.md를 참고해서 이어서 개발해줘. 다음 작업은 ◯◯이야."
  • 코드는 여러 파일로 나뉘어 있으므로(4.2절) 고칠 기능에 해당하는 파일만 보면 됩니다.
  • DB를 바꾸는 작업이면 supabase/migrations/에 SQL을 남기고, 되돌리기 SQL도 supabase/rollback/에 함께 둡니다(12절의 절차 참고).
  • 3D 화면을 바꾸는 작업이면 조명 개수를 늘리지 않는 것이 원칙입니다(8절·10절). 새 장식의 밝기는 발광(emissive) 재질이나 조명 영향을 받지 않는 재질로 냅니다.
  • 다음 큰 작업 후보인 "여러 반 전시 동시 공개"의 설계안은 14절에 정리해 두었습니다.

2. 목표 및 배경

  • 미술 시간에 완성한 작품을 교실 벽에만 걸어두지 않고, 언제 어디서나 들어가 볼 수 있는 전시관으로 만들어 주기 위해 시작했습니다.
  • 교사는 사진 파일을 한 번에 올리기만 하면 되고(파일명으로 이름·제목 자동 입력, 전시실 자동 배정), 학생·학부모는 QR코드 하나로 바로 입장합니다.
  • 감상 활동(좋아요·댓글)을 교사가 감상 결과 리포트로 내려받아 평가 자료로 활용할 수 있습니다.
  • Phase 7은 여러 선생님이 함께 쓰기 위한 보안·교사별 전시 분리, Phase 8~9는 "진짜 미술관에 온 느낌"(전시실 테마·밝은 로비)이 목표였습니다.
  • Phase 10은 쓰기 편하고 안전하게가 목표였습니다. 전시를 만들 때부터 테마를 고르게 하고, 고를 수 있는 테마를 늘리고, 로비 창밖이 계절·시간에 따라 달라지게 했습니다. 학생들이 쓰는 공간이므로 댓글 욕설을 DB에서 막는 필터도 더했습니다.

3. 주요 기능

감상(학생·학부모)

  • 로그인 없이 입장, QR코드·공유 링크(?t=교사코드)로 해당 교사의 현재 전시 관람
  • 1인칭 이동: PC는 WASD + 방향키 + 마우스 클릭, 모바일은 자체 구현 조이스틱 + 드래그 + 탭
  • 로비 → A동 전시실들 → 연결 통로 → B동 전시실들 → 로비로 돌아오는 순환(ㅁ자) 동선
  • 밝은 화이트 로비: 통유리벽 너머 정원, 테라초 바닥, 천장 선 조명, 창가 벤치·화분
  • [Phase 10] 로비 창밖 풍경이 계절(봄 꽃·여름 녹음·가을 단풍·겨울 눈)과 시간대(낮·노을·밤하늘)에 따라 바뀜
  • 전시실 테마 9종: 클래식(기본)·화이트 큐브·숲속 정원·바닷속·밤하늘·크레파스 놀이터 + [Phase 10] 우주정거장·눈 내린 겨울·한옥. 테마마다 벽·바닥·천장 무늬, 액자, 강조색, 소품이 달라짐
  • 소품·벤치·화분에는 부딪힘 처리
  • 작품 확대 보기, 좋아요(방문자 키로 중복 방지), 댓글(이름 10자·내용 80자)
  • [Phase 10] 댓글 부적절어 필터: 욕설·비속어가 들어간 이름·댓글은 저장되지 않고 "바르고 고운 말로 다시 써 주세요" 안내
  • 스마트폰 뒤로 가기 시 열린 창만 한 단계씩 닫힘

관리(교사)

  • 회원가입 → 관리자 승인 후 사용
  • 저장된 로그인 정보로 다시 들어올 때 입력 칸 대신 "저장된 로그인 정보로 들어가는 중이에요…" 안내 (v9 이후 개선)
  • 새 전시 만들기: 폴더/여러 장 업로드, 파일명(번호_이름_제목.jpg) 자동 해석, 방 자동 배정(방당 8점 기준 균등 분배), 진열 순서(이름순·랜덤·직접)
  • [Phase 10] 새 전시 만들 때 전시실마다 테마·소품 표시 고르기, 전시실 2개 이상이면 "모든 전시실 한 번에"
  • 기존 전시 관리: 정보 수정, 작품 수정·삭제·순서 변경, 작품 추가, 전시 삭제, 전시실별 테마 변경(바꾸면 바로 저장)
  • 현재 전시장 설정: 교사마다 하나의 전시를 방문자에게 공개(is_active)
  • 관리자 화면 상단의 "우리 반 링크" 표시·복사
  • 댓글 숨김/복원, 감상 결과 리포트(오프라인 HTML 파일) 다운로드
  • 관리자 전용 교사 승인 탭
  • 시작·로그인 화면 "미술관 입장권" 디자인
  • 전시장 안 오른쪽 위 "↩ 처음 화면으로"(로그아웃 없이 시작 화면으로)와 로그아웃 버튼

10. 보안·성능 고려사항

보안

  • anon key는 공개되어도 되는 키이며 보호는 RLS가 담당합니다. Service Role Key는 절대 코드에 넣지 않습니다.
  • Supabase Auth: 회원가입 허용(승인제), 이메일 인증 켬, Google 로그인 꺼짐(버튼 숨김).
  • 보안 진단 현황(Phase 10 적용 후 재확인, 새 경고 없음): 방문자용으로 의도적으로 공개한 SECURITY DEFINER 함수 경고 2건(get_active_exhibition, like_counts), 유출 비밀번호 차단 꺼짐 경고 1건.
  • rooms.theme은 체크 제약으로 9개 값만 허용. 앱도 모르는 키는 클래식으로 처리.
  • 댓글 필터: 트리거 함수는 security definer + search_path = ''. 금지어·예외 표와 필터 함수는 public·anon·authenticated 권한을 모두 회수해 방문자가 목록을 읽거나 함수를 직접 부를 수 없음(적용 후 anon 읽기 권한 없음 확인).
  • 저장된 로그인 확인 중 안내는 화면 표시만 바꾼 것이며, 실제 권한 판단(승인 상태 확인)은 그대로 enterWithSession이 함.

성능 (3D)

  • 조명 개수는 처음 한 번 정한 뒤 바꾸지 않습니다. 새 장식은 발광 재질이나 MeshBasicMaterial로 밝기를 냅니다.
  • 그림자는 현재 방 작품 조명만(그림자맵 768). 가까운 방(2칸 이내)만 조명을 배치.
  • 테마 재질은 테마별로 한 번만 만들어 재사용. 무늬 텍스처는 256~512px 캔버스(로비 하늘 1024×512, 나무 띠 2048×384).
  • 로비 풍경은 페이지를 열 때 한 번만 그림. 계절·시간대 12가지 모두 셰이더 수가 변경 전과 같음(16개).
  • 댓글 필터는 댓글 1건 저장 시 금지어 53개·예외 5개 문자열 비교뿐이라 부담이 거의 없음.

13. 알려진 한계

  • 교사마다 방문자에게 공개되는 전시는 하나입니다(여러 반 동시 공개는 14절 설계안, 보류 중).
  • 현재 전시는 공개용이라, API를 직접 다루는 사람은 다른 반의 현재 전시를 조회할 수 있습니다(지난 전시는 불가).
  • 좋아요 중복 방지는 브라우저 기준입니다.
  • 댓글 필터는 낱말 목록 방식입니다.
    • 목록에 없는 새 욕설·은어, 글자를 바꿔 쓴 변형(예: 비슷한 모양의 다른 글자), 욕설 없이 하는 놀림·비꼼은 막지 못합니다. 이런 댓글은 교사가 숨김으로 대응합니다.
    • 띄어쓰기를 지우고 비교하므로, 두 낱말이 이어 붙어 우연히 금지어가 되는 정상 문장이 드물게 막힐 수 있습니다. 발견되면 예외 목록에 넣습니다.
    • 목록 관리는 현재 SQL로만 할 수 있습니다(관리 화면 없음).
    • 필터 적용 전에 달린 댓글은 그대로입니다. 현재 '소인국 놀이터' 전시(원본과 test1 복사본)에 금지어가 든 댓글 1개씩이 숨김되지 않은 상태로 남아 있습니다.
  • 로비 풍경은 보는 사람 기기의 날짜·시각 기준입니다. 기기 시계가 틀리면 다른 계절·시간대가 보이고, 남반구·다른 시간대 기준은 고려하지 않습니다. 페이지를 연 채로 시간이 지나도 다시 열기 전까지는 바뀌지 않습니다.
  • 진열 순서를 created_at에 의존합니다.
  • JS 파일이 전역 변수를 공유하므로 불러오는 순서에 의존합니다.
  • 조명 개수를 늘리는 장식은 넣기 어렵습니다.
  • 테마를 추가하려면 코드(themes.js, props.js)와 DB 체크 제약을 함께 바꿔야 합니다.
  • 로비 유리문은 장식이고 바깥 정원은 그림입니다.
  • 작품 사진이 큰 편(약 1500×2000)이라 휴대폰 첫 입장 때 잠깐 버벅일 수 있습니다.
  • 발표용 테스트 계정의 복사본 전시는 원본과 이미지 파일을 공유합니다.
  • favicon.ico가 없어 콘솔에 404가 하나 남습니다.
